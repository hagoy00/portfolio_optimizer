# Portfolio Optimizer Dashboard

A professional, multi‑tab, institutional‑grade portfolio analytics dashboard built with **Streamlit**, featuring modern portfolio theory, risk analytics, Monte Carlo simulation, rebalancing backtests, sector exposure, AI commentary, and a full Buy/Hold/Sell signal engine.

This dashboard is designed for portfolio managers, analysts, and advanced retail investors who want a clean, interactive, and data‑driven environment for equity portfolio construction.

---

## 🚀 Features

### **1. Portfolio Optimization**
- Max‑Sharpe portfolio  
- Minimum‑volatility portfolio  
- Risk‑parity allocation  
- Efficient frontier visualization  
- Full performance metrics (return, volatility, Sharpe)

### **2. Risk Analytics**
- Drawdown curve  
- Maximum drawdown  
- Recovery behavior  
- Monte Carlo simulation with distribution analysis  

### **3. Rebalancing Backtest**
- Month‑end, weekly, and quarterly rebalancing  
- Portfolio value over time  
- Final value comparison  
- Clean, institutional layout  

### **4. Sector Exposure**
- Automatic sector mapping  
- Sector weight visualization  
- Allocation table + bar chart  

### **5. Weights & Shares**
- Optimized weights  
- Share allocation based on purchase power  
- Clean two‑column layout  

### **6. AI Commentary**
- Portfolio overview  
- Risk commentary  
- Sector insights  
- Risk‑parity comparison  
- Clean expandable sections  

### **7. Buy Analysis Engine**
- RSI, MACD, Bollinger Bands  
- 20‑day momentum & 200‑day trend  
- Valuation metrics (PE, PB, PS)  
- Analyst recommendations  
- Composite scoring system  
- Color‑coded BUY / HOLD / SELL signals  
- Per‑ticker technical charts
